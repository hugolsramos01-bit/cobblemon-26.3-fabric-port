# Minecraft 26.3 validation guide

Run commands from the repository root with JDK 25. Each command should be evaluated independently so a failure in one suite does not hide the result of another.

```shell
./gradlew :common:test --console=plain
./gradlew :fabric:runGameTest --console=plain
./gradlew :fabric:runClientGameTest --console=plain
./gradlew :fabric:validateAccessWidener --console=plain
./gradlew :fabric:releaseJar --console=plain
```

The migration added server and client GameTests for packet codecs, persistence, the Pokédex and scanner, recipes and machines, battle flows, flight/riding, entity visibility recall, and rendering setup. Check the `fabric/src/gametest` tree for the current scenario list.

GameTests do not cover every species, graphics driver, resource-pack combination, or external server setup. Before a release, also install the built JAR outside Gradle in a clean Fabric 26.3 profile, create a disposable world, and exercise a dedicated server with at least two clients. Record any unrun platform or optional-mod combinations separately.
