An independent build of the public MoLang source at the current repository head (identical Java sources to `c7ea766d`, but newer build configuration and JDK 21) produced 86 class files; 42 of the original JAR's 87 classes matched byte for byte. This does not rule out matching source compiled under different tools, and is why the exact revision and build remain a question.

The original JAR's `MoLangMath.class` ZIP timestamp is 2025-09-19 10:31:28, seven seconds after the source commit's recorded local time. Its `ExprTraverser$1.class` has a March 2025 ZIP timestamp and was absent from the independent clean build. An incremental build with retained output is one possible explanation; the timestamps alone are not proof.
