# 26.3 port provenance review

This review compares the candidate with Cobblemon upstream commit `7511facebce13cc86706d49ae7ebab515e862fc8`. It describes what was inspected; it is not a determination that every dependency and asset is cleared for every form of distribution.

## Source and resources

| Material | Evidence and disposition |
| :--- | :--- |
| Cobblemon source and assets | The upstream Git history through the base is retained. Root `LICENSE` and existing asset license files remain present. The port's source and data migration are in the candidate branch. |

Most changes are migrated advancements, loot tables, recipes, item definitions and worldgen data. The Repurposed Structures compatibility data was moved within the existing resource tree. ## Dependencies and attribution

`gradle/libs.versions.toml` and `fabric/build.gradle.kts` identify the active dependency versions and how they are used. This branch updates Fabric, Kotlin, Graal and JEI versions. JEI and Mod Menu are optional integrations; 1.21.1 debugging helpers are opt-in and are not normal runtime dependencies.

The tested `releaseJar` contains 18 nested runtime JARs for Fabric Language Kotlin, Fabric Permissions API, GraalVM and MongoDB. Inspection found a license notice in the Fabric Language Kotlin nested JAR, while the other 17 had no file named `LICENSE` or `NOTICE` in their archives. Sampled original downloaded JARs likewise lacked such files. Absence of a file does **not** establish that a library has no license or notice requirements. For example, the [MongoDB Java driver](https://github.com/mongodb/mongo-java-driver) states Apache 2.0, and [GraalJS](https://github.com/oracle/graaljs) states UPL 1.0 for its community distributions; verify the exact versions, components, transitive dependencies and required notices individually.

The root code license is [MPL 2.0](../LICENSE). Some individual Pokémon model folders contain their own Creative Commons licenses; the [upstream Cobblemon Assets license](https://gitlab.com/cable-mc/cobblemon-assets/-/blob/master/LICENSE) specifies CC BY-NC 3.0 for that assets project. Do not assume that a single license applies to every asset or library.

## Before publishing binaries

- Identify the exact source, license and any exceptions of the bundled modified MoLang artifact, then determine and satisfy its distribution obligations.
- Inspect the exact dependency artifacts and their transitive license and notice requirements; add the appropriate third-party notices to any distributed JAR or release.
- Review any external model/data sources that are not established by the upstream base.
- Repeat the history and secret scan against the exact branch and tags being published. Never publish the separate private repository or all local refs.

The candidate branch's external server startup, client initialization and automated checks are summarized in the [review brief](26.3-review-brief.md). User-confirmed ambient playback is recorded there separately from automated checks.
