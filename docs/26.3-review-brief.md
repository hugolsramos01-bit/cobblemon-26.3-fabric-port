# Minecraft 26.3 Fabric port: review brief

This is an experimental, community-maintained port of Cobblemon to Minecraft 26.3. It starts from upstream commit `7511facebce13cc86706d49ae7ebab515e862fc8`. It targets Fabric and Java 25. NeoForge and TBCS are outside the current scope.

The port covers Minecraft API migration across rendering, GUI, networking, persistence, world generation, recipes and machines. It also includes gameplay changes beyond compatibility: riding and flight controls, aerial Pokémon spawning and movement, and throwing a Pokémon to initiate a wild battle. These behavior changes need design review separately from the mechanical migration.

Follow-up changes include Pokémon face culling and emissive layer fixes, animation evaluation and geometry reuse, and reduced repeated work in aerial spawn checks and berry rendering. Performance benefits are workload-dependent; no universal improvement is claimed.

## Verification and remaining work

The `af10b7a` source revision passed `:common:test`, `:fabric:runGameTest` (34 required server tests), `:fabric:runClientGameTest`, `:fabric:validateAccessWidener` and `:fabric:releaseJar` on Java 25. Its installable Fabric JAR started and stopped a dedicated server in a separate directory. An external Fabric client initialized using the same JAR and loaded a generated ambient pack; actual playback was not exercised. These results do not establish full compatibility across all addons, devices, worlds or multiplayer configurations. Audio playback, gameplay in the external client and two authenticated players remain to be checked.

The port is a large review snapshot. A discussion with maintainers should establish whether to pursue a coordinated migration branch and how to split API changes, behavior changes, visual fixes and optimizations into reviewable contributions. No upstream acceptance or affiliation is implied.

## Resources and licensing

The original root `LICENSE` and per-asset licenses are retained. Code and individual assets can have different terms; consult their notices. The 864 privately supplied audio files are not part of this candidate, and the original sound event mappings remain intact. The optional ambient pack tool only packages audio provided by the player.

The eight binary resources changed since the base consist of seven existing habitat structure files and a King's Rock texture whose bytes match an existing upstream wearable texture. This inventory is not an exhaustive provenance or license review of every text-based asset and dependency.
