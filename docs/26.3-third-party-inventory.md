# Third-party components in the 26.3 candidate

This is a working inventory for the `af10b7a` Fabric release JAR, not a completed notice file or legal determination. The outer JAR has 18 nested JARs; Fabric Language Kotlin contains 13 additional nested JARs. MoLang classes are bundled directly into the outer JAR. A binary release needs the applicable license texts, copyright and NOTICE information for the exact artifacts, and confirmation of MoLang's source and distribution conditions.

## MoLang

- `local.com.bedrockk:molang:1.1.20`: inherited from the Cobblemon base. The Cobblemon team maintains a [public modified MoLang repository](https://gitlab.com/cable-mc/molang). Commit [`c7ea766d0b032386258f485edebe8893e2d56f7e`](https://gitlab.com/cable-mc/molang/-/commit/c7ea766d0b032386258f485edebe8893e2d56f7e) declares version `1.1.20` and adds `math.sign` and `math.copy_sign`. Three minutes later, the same author added the artifact to Cobblemon in [commit `6ae375cf4e`](https://gitlab.com/cable-mc/cobblemon/-/commit/6ae375cf4e1035778a450e956eada6683ebb2720). The ZIP timestamp for `MoLangMath.class` is seven seconds after the source commit's local timestamp; the JAR also contains an `ExprTraverser$1.class` timestamped March 2025 which was not produced by the independent clean build. This suggests the original build may have contained stale output, but timestamps alone do not prove its build process. An independent build did not reproduce every class byte for byte; the exact source and build parameters are not yet established.
- The MoLang repository at that source revision contains the [GNU GPL version 3 license](https://gitlab.com/cable-mc/molang/-/blob/c7ea766d0b032386258f485edebe8893e2d56f7e/LICENSE). The bundled JAR contains no license text or source information. No separate exception or permission was found in the inspected public repository. Confirm the applicable terms and any exceptions with the maintainers and determine the obligations for the combined distribution before release.
- SHA-256 of the inherited artifact: `c25ad69028b1489d985b5c7e3dd3d1d58ae10595e5e78d0b50c0919d9a8068ba`.
